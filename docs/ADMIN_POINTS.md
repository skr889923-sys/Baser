# إدارة نقاط التوجيه

من لوحة الإدارة، افتح **النقاط الملاحية والوصف الصوتي** (`/points`). زر القلم يفتح بيانات النقطة الحالية؛ احفظ التعديلات لتحديثها، أو اضغط إلغاء لتركها كما هي. يمكن تعديل الأسماء والنوع والمبنى والطابق والإحداثيات والوصف والتوجيه الصوتي وحالات التفعيل والخطر والوصول. النقاط الخارجية لا تتطلب مبنى، والنقاط الداخلية لا تتطلب إحداثيات جغرافية. لا تضيف الواجهة إحداثيات افتراضية.

من محرر الخريطة، اضغط علامة النقطة ثم **تعديل بيانات النقطة** للوصول إلى النموذج نفسه.

زر سلة المهملات يطلب تأكيد الحذف النهائي. لا تُزال النقطة من الجدول حتى ترسل قاعدة البيانات معرّف النقطة المحذوفة. تمنع قاعدة البيانات حذف نقطة مرتبطة ببداية مسار أو نهايته أو إحدى خطواته أو رمز QR، بما في ذلك المسارات المغلقة. أزل الارتباطات أولًا، أو عطّل النقطة إذا أردت إيقاف استخدامها مؤقتًا. يمنع هذا حذف خطوات من مسار قائم أو فقدان رموز QR وسجل مسحها دون قصد.

التعديل والحذف وتغيير الحالة متاحة لأدوار `super_admin` و`university_admin` و`building_manager`. إذا تغيّرت النقطة بعد تحميلها، تُرفض العملية وتظهر رسالة لتحديث القائمة. عند فشل الحفظ، تبقى مدخلات النموذج للمراجعة وإعادة المحاولة.

## تحديث قاعدة البيانات

طبّق [تحديث إدارة نقاط التوجيه](../supabase/migrations/20261007090000_navigation_point_management.sql) بعد تحديثي صلاحيات محرر الخرائط والسلامة التشغيلية. يضيف دالة الحذف المحمي `delete_navigation_point`؛ لا يحذف بيانات قائمة. عند غياب الدالة تعرض الواجهة رسالة تطلب التحديث، ولا تستبدله بحذف مباشر قد يحذف بيانات مرتبطة.

## التحقق المحلي

```bash
npm test
npm run lint
npx --no-install tsc -p apps/admin/tsconfig.json --noEmit --incremental false
python3 scripts/test-map-permissions.py --baseline init \
  --migration supabase/migrations/20260928090000_map_editor_permissions.sql \
  --route-migration supabase/migrations/20260928100000_route_step_schema_and_atomic_save.sql \
  --safety-migration supabase/migrations/20261003090000_operational_safety.sql \
  --point-migration supabase/migrations/20261007090000_navigation_point_management.sql
```

اختبارات SQL في `supabase/tests/` مخصصة لقاعدة محلية مؤقتة، وليست تحديثات تُنسخ إلى SQL Editor. لا تشغّلها على قاعدة الإنتاج.
